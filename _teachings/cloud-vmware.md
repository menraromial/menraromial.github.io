## Course Overview

Hands-on lab sessions (TP) on cloud computing infrastructure using **VMware vSphere** and **vCenter**. Students gain practical experience with virtualization technologies used in enterprise cloud environments.

### Key Topics
- Virtual machine provisioning and management
- VMware vSphere/vCenter administration
- Resource allocation and monitoring
- Cloud infrastructure deployment
